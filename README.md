# Платформа событий

Современное серверно-рендеринговое (SSR) веб-приложение, построенное на **Next.js**, для управления событиями, такими как выставки, литературные вечера или мастер-классы. Пользователи могут просматривать события, подписываться на них в качестве слушателей или создавать и редактировать собственные события в роли авторов. Проект демонстрирует навыки full-stack разработки, современный стек технологий и модульную архитектуру.

## Технологический стек

- **Фронтенд**:
  - **Next.js 13**: Для SSR и генерации статических страниц.
  - **React 18**: Компонентно-ориентированная разработка интерфейса.
  - **Tailwind CSS**: Утилитарный CSS-фреймворк для стилизации.
  - **React Hook Form**: Эффективная работа с формами.
  - **Zod**: Валидация схем для форм и API.
- **Бэкенд**:
  - **tRPC**: Типобезопасные API с полной интеграцией.
  - **Prisma**: ORM для взаимодействия с базой данных.
  - **NextAuth.js**: Управление аутентификацией и сессиями.
  - **SQLite**: Легковесная база данных (через Prisma).
- **Инструменты и утилиты**:
  - **TypeScript**: Статическая типизация для улучшения разработки.
  - **ESLint**: Проверка качества кода.
  - **PostCSS и Autoprefixer**: Обработка CSS.
  - **Superjson**: Расширенная сериализация JSON для tRPC.
    
## Основные возможности

- **Управление событиями**:
  - Просмотр списка событий с подробной информацией (название, описание, дата, изображение).
  - Детальные страницы событий с полной информацией.
  - Создание и редактирование событий (доступно для пользователей с ролью "автор").
- **Роли пользователей**:
  - **Слушатель**: Пользователи могут присоединяться к событиям или покидать их одним кликом.
  - **Автор**: Создатели событий могут редактировать свои события, обновлять детали и управлять контентом.
- **Аутентификация**:
  - Безопасная аутентификация пользователей через **NextAuth.js** с поддержкой регистрации и входа.
  - Управление доступом на основе ролей для ограничения редактирования.
- **Адаптивный интерфейс**:
  - Использование **Tailwind CSS** для современного и адаптивного дизайна.
  - Переиспользуемые UI-компоненты для карточек событий, форм и заголовков.
- **Управление данными**:
  - Использование **Prisma** ORM с базой данных SQLite (с возможностью масштабирования на другие базы).
  - Эффективные API-маршруты через **tRPC** для типобезопасного взаимодействия клиент-сервер.
- **Обработка форм**:
  - Надежная валидация форм с помощью **React Hook Form** и **Zod**.
- **Работа с данными в реальном времени**:
  - Интеграция **Tanstack React Query** для оптимизированного получения и кэширования данных.

## Начало работы

### Требования
- **Node.js**: v18 или выше
- **npm**: v8 или выше
- **SQLite**: Для базы данных (включено в Prisma)

### Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone git@github.com:AnastasiyaGuryanova/events-before-hw.git
   cd events-before-hw
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Настройте базу данных**:
   - Убедитесь, что схема Prisma (`prisma/schema.prisma`) настроена.
   - Выполните миграции:
     ```bash
     npx prisma migrate dev
     ```

4. **Настройте переменные окружения**:
   - Создайте файл `.env` в корневой папке.
   - Добавьте необходимые переменные (например, для NextAuth.js):
     ```env
     NEXTAUTH_URL=http://localhost:3000
     NEXTAUTH_SECRET=<ваш-секрет>
     ```

5. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в браузере.
